# Skylight Bridge app icon source

These three 1024 x 1024 SVG files are the flat source layers for the Relay Ribbon icon. Their numbering is the back-to-front order used by Icon Composer.

The Mac app builds its Liquid Glass icon from [`Resources/AppIcon.icon`](../../Resources/AppIcon.icon). Keep the SVG exports here as the editable design reference, not as generated build output.
